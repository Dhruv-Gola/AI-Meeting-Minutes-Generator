# AI Meeting Minutes Generator

An AI-powered web application that converts meeting transcripts
into structured meeting minutes.

## Project Duration

6 Weeks

## Objective

The application will allow users to upload or paste meeting
transcripts and use AI to generate structured meeting minutes.

## Core Features

- Meeting management
- Transcript upload
- AI-generated summaries
- Action items
- Decisions
- Risks
- Open questions
- Meeting history
- Meeting search
- PDF export
- TXT export
- Configurable AI prompt templates

## Technology Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL

### AI
- Google Gemini API
