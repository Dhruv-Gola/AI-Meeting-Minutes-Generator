# AI Meeting Minutes Generator
## Software Requirements

## 1. Project Objective

Build an AI-powered web application that converts meeting
transcripts into structured meeting minutes.

## 2. Functional Requirements

### 2.1 Meeting Management

The system should allow users to:

- Create a meeting
- View a meeting
- Update a meeting
- Delete a meeting

### 2.2 Transcript Management

The system should allow users to:

- Paste meeting transcripts
- Upload meeting transcripts
- Store meeting transcripts

### 2.3 AI Processing

The system should generate:

- Meeting summary
- Action items
- Decisions
- Risks
- Open questions

### 2.4 Meeting History

The system should:

- Maintain meeting history
- Display previous meetings
- Allow users to search meetings

### 2.5 Export

The system should allow users to:

- Export meeting minutes as PDF
- Export meeting minutes as TXT

### 2.6 Prompt Templates

The system should support:

- Creating prompt templates
- Storing prompt templates
- Using configurable AI prompts

## 3. Non-Functional Requirements

- Responsive UI
- Secure API key handling
- Error handling
- Logging
- Maintainable code
- Documented setup
